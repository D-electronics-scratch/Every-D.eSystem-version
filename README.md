# Every-D.eSystem-version

# Info about the versions
In this repositorie is every version of D.eSystem,all versions under D.eSystem 6 were simlations and OS prototypes,every version under D.eSystem 5 was written in Python. Every version under D.eSystem 4 runs in a online compiler and is not on github.

# D.eSystem 5

D.eSystem 5 was the biggest flop in D.electronics history,the flop had 2 reasons,the first reason was the architecture,the architecture was very bad because everything was in one big loop and it was very big,and if you type 1 wrong letter the entire system will crassh.

Reason 2 was that I shared D.eSystem 5 on reddit as a OS simulator OS prototype and gatekeeper said that I should delete D.eSystem or I should delete my posts,it got a lot of hate.

D.eSystem 5 was also the first D.eSystem written in C.

D.eSystem 5 github page: https://github.com/D-electronics-scratch/D.eSystem-5
